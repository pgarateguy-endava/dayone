# Endava profile guidelines (placeholder)

Placeholder for the internal Endava profile documentation. In production this content lives
in S3 and is indexed by a Bedrock Knowledge Base (journey B3 in `docs/BENCH_SPEC.md`).

A good profile update after bench should include:

- Summary refreshed with the latest project, role and impact.
- Skills section aligned to the discipline matrix, each with evidence (project, cert, repo).
- Certifications section up to date, including scheduled exams.
- Courses completed during bench with completion dates.
